# 💌 Sayali's Emotional Apology Website

A beautiful, interactive apology website with cinematic animations, a crying teddy bear, and emotional storytelling.

## 🌟 Features

- **Interactive Envelope Opening**: Click to open a sealed envelope with your message
- **5-Scene Story Journey**: 
  1. How you met on the dating app
  2. Your magical dinner date
  3. What went wrong (circumstances)
  4. Heartfelt apology with tear animation
  5. The big question - will she forgive you?

- **Two Endings**:
  - ✅ **YES**: Celebration with confetti, floating hearts, and WhatsApp integration
  - ❌ **NO**: Dark background with animated crying teddy bear and broken heart

- **Beautiful Animations**:
  - Floating hearts background
  - Smooth scene transitions
  - Bouncing icons
  - Tear drop effects
  - Confetti explosion
  - Pulsing buttons
  - Mobile swipe support

## 📁 Files Included

- `index.html` - Main HTML structure
- `styles.css` - All animations and styling
- `script.js` - Interactive functionality

## 🚀 How to Use

### Option 1: Open Locally
1. Simply double-click `index.html` to open in your browser

### Option 2: Host Online (Recommended)

#### Using Netlify (Easiest):
1. Go to [netlify.com](https://netlify.com)
2. Sign up for free
3. Drag and drop the `sayali-emotional-site` folder
4. Get your live link instantly!

#### Using GitHub Pages:
1. Create a GitHub account
2. Create a new repository
3. Upload all three files
4. Enable GitHub Pages in settings
5. Share the link with Sayali!

## ⚙️ Customization

### IMPORTANT: Update WhatsApp Number
Open `script.js` and find this line (around line 67):
```javascript
const phoneNumber = "919876543210"; // Replace with your actual number
```
Replace `919876543210` with your phone number in international format (no + sign).

### Customize Messages
Edit the text in `index.html`:
- Scene 1: Your meeting story
- Scene 2: Dinner date memories
- Scene 3: What went wrong
- Scene 4: Your apology message
- Scene 5: The forgiveness question

### Change Colors
In `styles.css`, modify the gradient colors:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
