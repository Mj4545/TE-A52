# ❤️ Apology Website for Sayali

A beautiful, cinematic interactive website to express your heartfelt apology.

## 🌟 Features

- **Animated floating hearts** background with various heart emojis
- **5-scene storytelling** experience:
  1. How you met on the dating app
  2. Your magical dinner date
  3. Acknowledging what went wrong
  4. Heartfelt apology message
  5. Hope for reconciliation
- **Interactive choices** - She can forgive or ask for time
- **Confetti celebration** when she forgives you
- **WhatsApp integration** to continue the conversation
- **Cinematic animations** including heartbeat effects
- **Fully responsive** design for mobile and desktop
- **Beautiful gradient backgrounds** with glass-morphism cards

## 🚀 How to Use

### Option 1: Open Locally
1. Simply open `index.html` in any web browser (Chrome, Firefox, Safari)
2. Share the file or record your screen to show her

### Option 2: Host Online (Recommended)

#### Using Netlify (Easiest):
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the `sayali-cinematic-site` folder
3. Get a live link instantly (e.g., `your-site.netlify.app`)
4. Share the link with Sayali!

#### Using GitHub Pages:
1. Create a GitHub repository
2. Upload all files from this folder
3. Enable GitHub Pages in settings
4. Share the link

## ✏️ Customization

### Update WhatsApp Number
Open `index.html` and find this line (around line 73):
```html
<a href="https://wa.me/91XXXXXXXXXX?text=Hi,%20I%20saw%20your%20message...%20let's%20talk%20❤"
```
Replace `91XXXXXXXXXX` with your actual phone number (include country code, no spaces or + sign).

### Change Story Messages
Edit the text inside each scene in `index.html`:
- Scene 1: Your meeting story
- Scene 2: Date night memories
- Scene 3: What went wrong
- Scene 4: Your apology
- Scene 5: Final message (dynamically changes based on her choice)

### Modify Colors
In `styles.css`, change the gradient in the `body` section:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 50%, #f093fb 100%);
```
