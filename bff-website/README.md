# BFF Website - A Special Gift for Your Best Friend 💕

This is a beautiful, interactive website created specially for your female best friend, featuring a heartfelt apology message and lots of love!

## 🌟 Features

- **Beautiful Design**: Pink gradient background with floating hearts animation
- **Photo Gallery Section**: Showcase your favorite memories together (replace emojis with actual photos!)
- **Why You're Amazing Section**: Highlight what makes her special
- **Heartfelt Apology Section**: A sincere apology message with an interactive forgiveness button
- **Confetti Celebration**: When she clicks the forgiveness button, confetti rains down!
- **Responsive Design**: Works perfectly on phones, tablets, and computers
- **Smooth Animations**: Fade-in effects and hover animations throughout

## 📁 Files Included

1. `index.html` - The main HTML structure
2. `styles.css` - Beautiful styling with pink theme
3. `script.js` - Interactive features and animations

## 🚀 How to Use

### Option 1: Open Locally
1. Navigate to the `bff-website` folder
2. Double-click on `index.html` to open it in your browser

### Option 2: Host Online (Free)
You can host this website for free using:

**GitHub Pages:**
1. Create a GitHub account if you don't have one
2. Create a new repository named `bff-website`
3. Upload all three files
4. Go to Settings → Pages
5. Enable GitHub Pages
6. Share the link with your BFF!

**Netlify:**
1. Go to [netlify.com](https://netlify.com)
2. Sign up for free
3. Drag and drop the `bff-website` folder
4. Get your live link instantly!

## ✏️ Customization Tips

### Add Real Photos
Replace the emoji placeholders in the photo gallery with actual images:

```html
<div class="photo-card">
    <img src="your-photo.jpg" alt="Your memory" style="width:100%; border-radius:10px;">
    <p>Adventure Time</p>
</div>
```

### Personalize the Apology
Edit the apology message in `index.html` to make it more personal and specific to your situation.

### Change Colors
Modify the color values in `styles.css` to match her favorite colors.

### Add Her Name
Replace "Your Forever BFF" with your actual name or nickname.
